# Change log

## Format

For each meaningful change, record:

- date;
- submodule;
- affected files;
- short rationale;
- validation artifact added or updated.

## Entry template

- **Date**: YYYY-MM-DD  
  **Submodule**: `phase-loop-mode0` / `dllrf` / `rf-phase-noise`  
  **Files**: `...`  
  **Reason**: `...`  
  **Evidence**: `...`
